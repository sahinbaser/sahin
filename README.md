# FinPro - Profesyonel Finansal Analiz Platformu

FinPro, yatırımcılar ve traderlar için geliştirilmiş, Web, Android ve iOS platformlarında çalışan kapsamlı bir finansal analiz uygulamasıdır.

## 🌟 Öne Çıkan Özellikler

1.  **Hisse Doğallık Analizi:** Fiyat ve hacim verileri üzerinden anomalileri tespit eder, manipülasyon riskini ölçer.
2.  **Temettü Simülatörü:** Finansal bağımsızlık (FIRE) hedeflerinizi hesaplar.
3.  **Duygusuz Trader Motoru:** RSI, MACD ve ATR kullanarak dinamik Al-Sat sinyalleri üretir.
4.  **Para Akışı Haritası:** Global sektörler, BIST ve Kripto piyasalarındaki sermaye hareketlerini izler.
5.  **İflas Riski (Z-Score):** Şirketlerin finansal dayanıklılığını ve iflas olasılığını modeller.

## 🛠️ Teknoloji Yığını
- **Frontend:** React Native (Expo), React Native Paper, React Navigation, Axios.
- **Backend:** Python (FastAPI), Pandas, NumPy, Scipy, yfinance.
- **Veritabanı & Auth:** Supabase.
